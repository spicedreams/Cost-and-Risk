To implement the Check-Out / Check-In model robustly, we must apply the OS-level atomic lock to a fixed directory name (e.g., project.sqlite.lockdir). If we included the username directly in the directory name itself, we would have to search for unknown lock names before creating one, which reintroduces the exact race condition we are trying to avoid.

To give you the visibility you need safely, the code below atomically creates the .lockdir, and upon winning that race, writes a file inside it explicitly named locked_by_[USERNAME].txt.

Here are the specific updates to Section 1 and Section 3 of your code.

1. Replace the Locking Helper Functions
In Section 1. HELPER FUNCTIONS & MATH ENGINE, replace the old acquire_db_lock and release_db_lock functions with these three new functions:

R
acquire_db_lock <- function(network_path, rv) {
  if (is.null(network_path) || network_path == "") return(FALSE)
  
  # The directory name itself is the atomic mutex. 
  lock_dir <- paste0(network_path, ".lockdir")
  
  # suppressWarnings prevents console spam if the directory already exists (which means it is locked)
  success <- suppressWarnings(dir.create(lock_dir))
  
  if (success) {
    user_info <- Sys.info()[["user"]]
    if (is.null(user_info) || user_info == "") user_info <- "UnknownUser"
    
    info_file <- file.path(lock_dir, paste0("locked_by_", user_info, ".txt"))
    try(writeLines(paste("Locked at:", Sys.time()), info_file), silent = TRUE)
    
    rv$lock_dir <- lock_dir
    return(TRUE)
  } else {
    # If we failed to lock, figure out who has it to warn the user
    occupant <- "another process"
    if (dir.exists(lock_dir)) {
      files <- list.files(lock_dir, pattern = "^locked_by_")
      if (length(files) > 0) {
        occupant <- gsub("locked_by_|.txt", "", files[1])
      }
    }
    showNotification(paste("Database is locked by:", occupant), type = "error", duration = 8)
    return(FALSE)
  }
}

release_db_lock <- function(rv) {
  if (!is.null(rv$lock_dir) && dir.exists(rv$lock_dir)) {
    unlink(rv$lock_dir, recursive = TRUE)
  }
  rv$lock_dir <- NULL
}

sync_to_network <- function(rv) {
  # Copies local database back to the network and deletes local temp to avoid multiple sources of truth
  if (!is.null(rv$db_path) && !is.null(rv$network_db_path)) {
    file.copy(from = rv$db_path, to = rv$network_db_path, overwrite = TRUE)
    unlink(rv$db_path)
  }
}
